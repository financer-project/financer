Restore native keyboard navigation through the transaction form: forward Tab reaches every date and select field in visual order, and Shift+Tab retraces that path exactly in reverse.

Contracts the executor needs without re-deriving them:

- `SelectField<T>` (`src/lib/components/common/form/elements/SelectField.tsx`) destructures `{ options, onChange, readonly, placeholder, multiple, onCreateNew, createNewLabel, ...props }`; `props` carries `value`, `className`, `keepPlaceholder`, `disableClearButton`. Local state: `isOpen` / `setIsOpen`, `search`, `internalValue`. The trigger lives at lines 202-231.
- `InputGroup` (`src/lib/components/ui/input-group.tsx`) is `<div data-slot="input-group" role="group" {...props} />`. Its class list includes `outline-none`, and its focus ring is keyed on `has-[[data-slot=input-group-control]:focus-visible]` — that selector matches a focused **inner control**, so a focused wrapper element gets no ring from the shared styles. Any focus indicator must be added on the `SelectField` instance's own `className`.
- `InputGroup` is shared: `SelectField` uses it for the select trigger, and `TableToolbar.tsx` uses it for plain search inputs that already contain a natively focusable `<input>`.
- Radix behaviour verified in `node_modules` during research: `PopoverTrigger asChild` resolves `Primitive.button` to `Slot`, and `Slot`'s `mergeProps` merges only event handlers, `style`, `className` and pass-through props. It injects no tab index and adds no key handler, so Enter/Space activation must be supplied by the consumer.
- `DatePicker` (`src/lib/components/common/form/elements/DatePicker.tsx`) uses the same `PopoverTrigger asChild` pattern but wraps a real `<Button>` (natively focusable) plus a second conditional clear `<Button>` when a date is set.
- `TransactionForm.tsx` DOM order, top to bottom: Account select · Name text input · Value Date picker · Type select · Amount input · Description textarea · Category select · Counterparty select · Tags select · submit button.
- `cypress-real-events` exposes `cy.realPress("Tab")` and `cy.realPress(["Shift", "Tab"])` once `cypress-real-events/support` is imported in the support file. It drives Chrome DevTools Protocol and requires a Chromium-family browser; the suite already runs `--browser chrome`.
